# Network Meta-Analysis and Meta-Regression of Diagnostic Tests for Sepsis

## プロジェクト概要

このリポジトリは、敗血症（セプシス）の診断に用いられる複数のバイオマーカーと臨床スコアリングシステムの性能を評価するための**ネットワークメタアナリシス**および**メタ回帰分析**に関する研究プロジェクトです。

敗血症は迅速な診断と治療が必要な重篤な全身性感染症であり、適切なバイオマーカーの選択が重要です。このプロジェクトでは、様々な診断マーカー（qSOFA, PCT, presepsin, CRP, CD64, IL-6, sTREM-1, LBP, SIRS, SOFAなど）の診断精度を比較・評価し、臨床現場での意思決定を支援するためのエビデンスを提供します。

ベイジアンネットワークメタアナリシスを用いることで、直接比較研究がない診断マーカー間でも相対的な診断性能の比較が可能になります。

## データセット

このプロジェクトでは以下のデータセットを使用しています：

- **Sepsis_nma_data.csv**: 敗血症診断のための様々なバイオマーカーの感度・特異度データを含む主要データセット
- **Sepsis3_since2016_20241119.csv**: Sepsis-3定義が導入された2016年以降の研究に焦点を当てたデータセット

各データセットには、研究情報（著者、年、タイトル）、バイオマーカー情報、検体タイプ、感度、特異度、サンプルサイズ、カットオフ値などの情報が含まれています。

### 評価対象バイオマーカー

このプロジェクトで評価対象となっている主なバイオマーカーとスコアリングシステム：

- **qSOFA** (quick Sequential Organ Failure Assessment): 臓器機能不全の迅速評価スコア
- **PCT** (Procalcitonin): 炎症マーカーであるプロカルシトニン
- **presepsin**: 単球・マクロファージ系の活性化を反映する可溶性CD14サブタイプ
- **CRP** (C-Reactive Protein): 急性期タンパク質である C反応性タンパク
- **CD64**: 好中球表面の高親和性FcγレセプターI
- **IL-6** (Interleukin-6): 炎症性サイトカイン
- **sTREM-1** (soluble Triggering Receptor Expressed on Myeloid cells-1): 可溶性トリガー受容体
- **LBP** (Lipopolysaccharide Binding Protein): リポ多糖結合タンパク質
- **SIRS** (Systemic Inflammatory Response Syndrome): 全身性炎症反応症候群の基準
- **SOFA** (Sequential Organ Failure Assessment): 臓器機能不全評価スコア

## 分析手法

### ベイジアンネットワークメタアナリシス

このプロジェクトでは、ベイジアンネットワークメタアナリシスを用いて敗血症診断テストの性能を評価しています。このアプローチは以下の利点があります：

1. 直接比較がないマーカー間の間接的な比較が可能
2. 様々な研究からのエビデンスを統合可能
3. 研究間の異質性を考慮した推定が可能
4. 診断性能の不確実性を評価可能

### Stanによるモデリング

分析には**Stan**（ベイジアン統計モデリングプラットフォーム）を使用しています。主要なモデルは以下の通りです：

1. **標準ネットワークメタアナリシスモデル**: 共変量を考慮せず、マーカー間の比較を行うモデル
2. **メタ回帰モデル**: 有病率などの共変量を考慮したモデル

### 評価指標

分析では以下の指標を用いて診断性能を評価しています：

- **感度（Sensitivity）**: 実際に陽性の患者を正確に検出する能力
- **特異度（Specificity）**: 実際に陰性の患者を正確に識別する能力
- **相対リスク（RR、Risk Ratio）**: リファレンスマーカーに対する相対的なリスク
- **オッズ比（OR、Odds Ratio）**: リスクのオッズの比
- **診断オッズ比（DOR、Diagnostic Odds Ratio）**: 診断の正確性の総合指標
- **サマリーインデックス（S, S_se, S_sp）**: 診断性能の総合評価

## インストールと実行方法

### 必要環境

- R 4.0.0以上
- RTools 4.0以上（Windows環境の場合）

### セットアップと実行手順

1. リポジトリをクローンまたはダウンロードします
   ```
   git clone https://github.com/yourusername/Network-meta-analysis-and-meta-regression-of-diagnostic-tests.git
   cd Network-meta-analysis-and-meta-regression-of-diagnostic-tests
   ```

2. 環境のセットアップを行います。これにより必要なパッケージがインストールされます
   ```r
   source("setup.R")
   ```

3. 設定ファイル（config/config.yml）を必要に応じて編集します
   - マーカーのリスト
   - MCMCのパラメータ（反復回数、チェーン数など）
   - 乱数シード
   - メタ回帰分析の設定

4. 分析を実行します
   ```r
   source("main.R")
   ```

5. 結果は `results/[タイムスタンプ]` ディレクトリに保存されます
   - 感度・特異度、DOR、サマリーインデックスなどのCSVファイル
   - 視覚化されたプロット（PNG形式）
   - 再現性のための実行情報（run_info.json）

## 主な機能

- **モジュラー構造**: 関数ごとにファイルを分割し、保守性と理解しやすさを向上
- **設定ファイル**: 外部YAMLファイルによるパラメータ管理で柔軟な設定変更が可能
- **タイムスタンプ付き結果保存**: 実行ごとに結果が別々に保存され、上書きの心配なし
- **自動ドキュメント化**: 実行情報を自動的に記録して再現性を確保
- **可視化**: 結果を自動的に視覚化して解釈を容易に
